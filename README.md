# Geometric Neon Cyberpunk - Tower Defense

Браузерная Tower Defense игра в неоновом геометрическом киберпанк-стиле на чистом JavaScript с архитектурой ECS (Entity Component System).

## 🎮 Особенности

* **Чистая ECS Архитектура:** Разделение данных и логики на компоненты (`Transform`, `Health`, `Armor`, `Attack`, `CircleCollider`, `Projectile` и др.) и изолированные системы (`MovementSystem`, `TargetingSystem`, `CollisionSystem`, `DamageSystem`, `WaveSystem`, `ParticleSystem`, `RenderSystem` и др.).
* **Разнообразные архетипы врагов:**
  * **Разведчик (Scout):** Быстрый треугольник, нападающий роем.
  * **Истребитель (Fighter):** Стремительный клиновидный дрейфующий дроид.
  * **Танк (Tank):** Тяжелый бронированный шестиугольник с повышенным запасом прочности.
  * **Снайпер (Sniper):** Дальнобойный ромб, останавливающийся на дистанции атаки и ведущий огонь лазерными снарядами.
  * **Эгида (Aegis):** Бирюзовый пятиугольник с силовым куполом, снижающим входящий урон по союзникам внутри купола на 50%.
  * **Сплиттер (Splitter):** Треугольный фрактал Серпинского, распадающийся при гибели на 3 быстрых осколка с отскоком назад и в стороны.
  * **Блинкер (Blinker):** Белый зигзаг-молния, совершающий телепорт-рывок каждые 2 секунды со сбросом наведения летящих снарядов.
* **Системные Боссы:**
  * **Архитектор (The Architect):** Выходит каждую 10-ю волну (10, 20, 30...). Гигантский 8-конечный звездный фрактал, защищенный кольцом вращающихся физических щитов-сегментов на орбите. Чтобы нанести урон ядру, необходимо пробить брешь в щитовом кольце.
* **Гибкая система улучшений:** 24 параметра, включая рикошеты, быструю атаку, отражение, вампиризм, отталкивание и бесплатные уровни за волну. Цифры и ограничения первого баланса описаны в [docs/upgrades-balance.md](docs/upgrades-balance.md).
* **Интерактивное аудио:** Процедурные звуковые эффекты на Web Audio API и цикличный саундтрек.
* **Управление скоростью:** Поддержка скоростей x1, x2, x3 (клавиши `1`, `2`, `3`).
* **Индикаторы HP:** Секционное кольцо встроено в броню башни и рисуется под стволом. Кольцо и полоска в интерфейсе плавно меняют цвет по доле здоровья: зелёный при 100%, жёлтый при 50%, красный при 0%. Общая шкала — `src/visuals/HealthVisuals.js`.

## 🚀 Запуск игры

### Вариант 1: Через скрипт (Windows)
Запустите файл `start.bat`. Он автоматически поднимет локальный сервер на Node.js или Python и откроет игру в браузере по адресу `http://localhost:8080/`.

### Вариант 2: Через Node.js
```bash
node server.js
```
Откройте `http://localhost:8080/` в браузере.

### Вариант 3: Через Python
```bash
python -m http.server 8080
```
Откройте `http://localhost:8080/` в браузере.

## Телефоны и планшеты

Интерфейс переключается по доступному размеру окна, без определения модели устройства:

- Панель улучшений всегда открыта: в портретной ориентации внизу, в альбомной — сбоку. Категории «Атака», «Защита» и «Экономика» переключаются вкладками; нажатие на карточку покупает улучшение.
- Скорость ×1/×2/×3 переключается кнопками − и +, между ними расположена пауза. Башня автоматически атакует ближайшую цель и заранее наводится на врагов за пределами дальности атаки. Звук, музыка и FPS доступны в меню паузы.
- Меню, справочник и улучшения прокручиваются пальцем. Вырезы экрана учитываются через safe-area.
- При уходе в другую вкладку или приложение бой ставится на паузу. Для продолжения нажмите ▶.
- Canvas учитывает плотность пикселей с ограничением масштаба и размера буфера для мобильных GPU.

Для проверки на телефоне запустите `node server.js` на компьютере. Подключите телефон к той же локальной сети и откройте `http://IP-компьютера:8080/` в его браузере. `localhost` на телефоне указывает на сам телефон.

Проверки логики: `node --test tests/*.test.mjs`. Они проверяют ресайз, сохранение координат, паузу, синхронизацию управления и боевые механики; визуальный плейтест на Android Chrome и iOS Safari выполняется отдельно. Проверьте обе ориентации, покупку последнего улучшения после прокрутки, возврат из фонового режима и слайдеры звука.
